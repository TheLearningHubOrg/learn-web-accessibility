Accessible Component Examples

Each page below is a small, framework-free component built to WCAG 2.2 AA. They are covered by an automated axe-core scan and by keyboard interaction tests written in Playwright.

  • Modal dialog: native <dialog>, focus moved in on open and restored on close.
  • Tabs: roving tabindex, arrow keys, Home and End.
  • Form validation errors: error summary, inline messages and aria-invalid.
